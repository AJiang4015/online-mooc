# 天机学堂 AI 知识库测试文档

## 文档用途

这是一份专门用于测试知识库问答功能的 Markdown 文档。

如果知识库检索正常，AI 在回答问题时应该优先引用这份文档中的内容，而不是随意发挥。

## 项目背景

天机学堂是一个在线学习平台，包含课程学习、考试练习、支付下单、媒体上传、AI 对话等功能模块。

当前测试环境约定如下：

- 前端学习门户地址是 `http://localhost:18082`
- AI 对话服务名称是 `chat-service`
- AI 知识库使用的是 `Qdrant` 作为向量数据库
- 默认聊天模型原本通过 `Ollama` 接入
- 现在项目也可以切换到兼容 OpenAI 接口的平台

天机学堂测试管理员的代号是 **海鸥**。

## 推荐测试问题

上传成功后，你可以在知识库问答里测试这些问题：

1. 天机学堂测试管理员的代号是什么？
2. AI 知识库联调用的演示课程名称是什么？
3. 演示课程一共有几个正式小节？
4. 项目测试口令是什么？
5. 本次知识库演示使用的城市是哪里？

## 预期现象

如果知识库问答链路正常：

- 回答应该能说出“海鸥”
- 回答应该能说出“跨境电商实战入门”
- 回答应该能说出“5 个正式小节”
- 回答应该能说出“蓝桥春雪”
- 回答应该能说出“杭州”

如果它答不出来，或者答成别的内容，通常说明以下某一步有问题：

- 文档没有成功上传到知识库
- 文档没有成功切片并写入向量库
- 检索时没有命中对应片段
- 实际调用的不是知识库问答接口，而是普通聊天接口
