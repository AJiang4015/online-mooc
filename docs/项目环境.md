本地操作系统 `hosts` 文件已配置以下域名映射，用于模拟生产/测试环境域名访问：

| :--- | :--- | :--- |
| `192.168.127.101` | `git.tianji.com` | 代码仓库 (Gitea/Gitlab) |
| `192.168.127.101` | `jenkins.tianji.com` | 持续集成服务 |
| `192.168.127.101` | `mq.tianji.com` | RabbitMQ 管理界面 |
| `192.168.127.101` | `nacos.tianji.com` | Nacos 注册/配置中心 |
| `192.168.127.101` | `xxljob.tianji.com` | XXL-JOB 任务调度平台 |
| `192.168.127.101` | `es.tianji.com` | Kibana/Elasticsearch |
| `192.168.127.101` | `api.tianji.com` | 后端网关入口 |
| `192.168.127.101` | `www.tianji.com` | 用户端门户网站 |
| `192.168.127.101` | `manage.tianji.com` | 管理后台前端 |

## 2. 基础架构说明

- **虚拟机环境**：所有中间件（MySQL, Redis, MQ, Nacos 等）均部署在 IP 为 `192.168.127.101` 的虚拟机 Docker 容器中。
- **Java 服务**：微服务实例（Gateway, System, Course 等）均启动在开发机本地（Localhost），通过网关进行转发。

## 3. Nginx 反向代理路由表

Nginx 部署在虚拟机（`192.168.127.101`）中，监听 `80` 端口。以下为核心路由逻辑：

| 访问域名 | 转发目标 (Proxy Pass) | 备注 |
| :--- | :--- | :--- |
| `git.tianji.com` | `http://192.168.127.101:10880` | Git 服务 |
| `jenkins.tianji.com` | `http://192.168.127.101:18080` | CI/CD |
| `mq.tianji.com` | `http://192.168.127.101:15672` | MQ 控制台 |
| `nacos.tianji.com` | `http://192.168.127.101:8848/nacos/` | 自动重写路径 |
| `xxljob.tianji.com` | `http://192.168.127.101:8880/xxl-job-admin` | 调度平台 |
| `es.tianji.com` | `http://192.168.127.101:5601` | Kibana |
| `api.tianji.com` | `http://192.168.127.1:10010` | 转发至开发机本地网关 |
| `www.tianji.com` | `html/tj-portal` | 静态资源 (门户) |
| `manage.tianji.com` | `html/tj-admin` | 静态资源 (管理端) |

> **注意**：
> - `api.tianji.com` 代理到了 `192.168.127.1`（通常为宿主机在虚拟网卡中的 IP），以便在本地 Debug 后端代码。
> - 前端静态页面中的 `/img-tx` 路径统一代理至腾讯云 COS 存储。

## 4. 开发规范摘要

- **语言**：Java
- **定位**：精通 Java 后端、虚拟机应用与微服务架构。
